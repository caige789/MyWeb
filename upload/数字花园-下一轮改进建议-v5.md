## P0 · 成就 API 偶发挂起（今天实测）

### 现象
`GET /api/achievements` **单次请求正常**（返回 8 个成就），但**连续/并发请求时偶发**报：

```
Error: The Workers runtime canceled this request because it detected that your Worker's code had hung and would never generate a response.
```

### 定位
- 该路由代码（`src/app/api/achievements/route.ts`）与 v4 **完全相同**——不是 v5 引入，是既有的偶发问题
- 路由本身逻辑简单（`achievement.findMany` + 可选 `user`/`userAchievement` 查询），数据库连接正常（`/api/stats` 同环境不挂）
- **最大嫌疑：Prisma WASM 客户端的并发实例问题**——`db.ts` 是模块级单例（`globalForPrisma.prisma ?? createClient()`），但 WASM 引擎 + Neon 驱动适配器在 workerd 下并发请求时可能竞争/死锁

### 修复建议（按顺序试）
1. **db.ts 加请求级隔离/复用保护**：确认单例在 Cloudflare Workers 的 isolate 里是否正确共享（`globalThis` 在 Workers 里每个 isolate 独立，理论上单例是每 isolate 一个——检查是否有重复创建实例或连接池耗尽）
2. **给 Prisma 操作加超时兜底**：WASM 查询包一层 `Promise.race` 超时（如 10s），超时返回 500 而不是让 Worker 挂起（至少不白屏/不拖垮整个 Worker）
3. **Neon 连接池**：`PrismaNeon` 适配器确认使用连接池 URL（`-pooler` 后缀已有）；检查是否因并发连接数超限被 Neon 挂起
4. 若 WASM 实例是根因：尝试 `@prisma/client/wasm` 的 `PrismaClient` 改为每请求创建 + 复用连接（或调研 OpenNext 下 Prisma 的推荐并发姿势）

### 验收
- 连续并发请求 `/api/achievements` 100 次，0 挂起；单请求延迟 < 500ms

## A. v5 新功能完善（本周）

### A1. 飞机大战关卡/Boss 系统核查（P1）
v5 新增 10 关卡 + 5 种 Boss（含护盾 Boss）：
- [ ] **手机触控验证**：Boss 弹幕密度 + 触控避障在手机上是否可玩（低端机帧率）；Boss 预警提示是否醒目
- [ ] **关卡进度保存**：现在关卡进度是内存态（刷新即丢）？建议进度存 localStorage 或 UserScore 关联（"最高关卡"成就）
- [ ] **Boss 血量/难度曲线**：护盾 Boss 破盾机制在触屏上的操作反馈（被击中提示、护盾可视化）
- [ ] 分数与关卡挂钩：通关关卡数计入排行榜/成就（现在 GameScore 只有单分数）

### A2. PVZ 全屏画布核查（P1）
v5 把 PVZ 画布改成 `fixed inset-0 w-screen h-screen`（全屏）：
- [ ] **iOS Safari 实测**：全屏 canvas 会不会被底部工具栏/刘海遮挡（`100vh` 在 iOS 会溢出——需用 `100dvh` 或 JS 动态高度）；页面滚动是否被禁用（全屏游戏不该能上下滚动）
- [ ] **返回/退出路径**：全屏时"返回"按钮是否可见可点；浏览器返回手势会不会误触发
- [ ] 全屏 canvas 的 `devicePixelRatio` 适配（全屏后 dpr 变化触发 resize 是否正确重设 transform）
- [ ] 植物卡片栏在全屏布局下的位置（现在还是页面底部横排？全屏时是否浮在画布上）

### A3. GameHall 动画性能（P2）
- framer-motion 入场动画（stagger 0.08s）在低端安卓机上滚动画卡不卡；**动画仅首屏一次，滚动回列表不应重播**（确认 `initial`/`whileInView` 用法）
- 非 canvas 游戏（2048/五子棋/扫雷等）在手机上的触控体验复查（Phase 2 声称优化过，需要真机验证）

## B. 新功能方向（承接路线图，按优先级）

### B1. 每日挑战 + 连续签到（最高价值）
- 新表 `DailyChallenge`（date/game/target/seed），日期做 seed（`YYYY-MM-DD` 哈希），每日一个目标
- 达成 + streak 计数，游戏大厅顶部展示今日挑战进度
- 免费层友好：无需外部服务，Neon 一表搞定

### B2. 博客增强
- 标签（`Tag`/`ArticleTag` 表）、搜索（ILIKE）、阅读量（viewCount + sessionStorage 防刷）
- 评论（`Comment` 表：articleId/parentId/楼中楼），头像用 DiceBear SVG 免费方案
- 富文本输出 `rehype-sanitize` 防 XSS（必做）

### B3. 新游戏（选 4 款）
数独（回溯生成）、黑白棋（贪心 AI）、弹幕增强（在 Aircraft 上做）、无尽跑酷 v2（皮肤/金币）
——全部套统一画布模板（逻辑缩放 + dpr≤2 + ResizeObserver）。

### B4. 工具扩充（每个 ≤1 天）
JSON 格式化、正则测试、二维码生成（前端 qrcode）、单位换算、Markdown 预览、IP/UA 查询。

### B5. 后台管理增强
留言管理（删除/屏蔽）、用户列表、近 7 日访问折线（recharts）、站点配置可视化（SiteConfig 表）。

### B6. 技术架构
- 开启 OpenNext **R2 增量缓存**（`open-next.config.ts` + R2 bucket，博客详情提速）
- 图片上传走 R2 + `next/image`
- 留言/注册按 IP 限频；API 错误写 `ErrorLog` 表可查
