# Task 11-c: 前端游戏开发 - 勇者冒险（横版冒险闯关游戏）

## 任务
在 `/home/z/my-project/src/components/games/AdventureGame.tsx` 创建横版卷轴冒险闯关游戏。

## 完成内容

### 游戏玩法
- 横版卷轴冒险，玩家控制蓝色勇士角色
- 角色可左右移动（A/D/方向键）、跳跃（W/空格/上箭头）、攻击（J/鼠标左键）
- 程序化无限生成地图：地面段、浮空平台、阶梯平台组、深渊间隙
- 地图上分布金币（+10分）和怪物
- 两种怪物：绿色史莱姆（慢速，1HP，+20分）和红色骷髅（较快，2HP，+50分）
- 怪物自动巡逻，碰到平台边缘转向
- 玩家踩怪头顶消灭（马里奥式），攻击键挥剑消灭
- 3条命，受伤1.5秒无敌闪烁，坠落深渊重生扣命
- 地图自动右滚+相机跟随，距离计数

### 技术实现
- 纯Canvas绘制，60fps游戏循环
- 高DPI适配（devicePixelRatio缩放）
- 所有游戏状态存储在单一ref对象`gRef`中，避免闭包陷阱和react-hooks/immutability规则
- 桌面端键盘+鼠标，移动端检测并显示4个虚拟按钮（左/跳/攻击/右）
- 虚拟按钮用JSX button实现（非Canvas内绘制），position absolute定位
- 分数系统：GET/POST `/api/games/scores`，game='adventure'
- 低频state更新（每6帧）避免性能问题

### 视觉效果
- 天空渐变背景+远景云朵视差
- 平台棕色土块+绿色草地纹理
- 金币3D旋转+闪光效果
- 史莱姆弹跳动画+眼睛跟随方向
- 骷髅飘浮效果+红色眼睛+血条
- 玩家跑步/跳跃动画（肢体变化）+剑挥砍弧线特效
- 收集金币/击杀怪物飘字效果
- 受伤无敌闪烁

### UI元素
- 顶部栏：返回按钮、游戏名、最高分
- 状态栏：分数、距离、生命（❤️）
- Canvas游戏区域
- 移动端虚拟按钮（仅移动端显示）
- 开始/结束遮罩
